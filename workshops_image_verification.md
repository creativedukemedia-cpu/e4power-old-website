# Workshops Image Verification

The Workshops & Training service page in preview now uses the uploaded pillar-specific images in the intended order: Educate uses the notebook-writing image, Empower uses the sticky-note planning image, Elevate uses the workshop audience image, and Engage uses the applauding audience image.

The card media loads from managed storage paths and defaults to a grayscale presentation. The page stylesheet includes the same hover and focus rule used on Speaking Engagements, transitioning each `.ref-card-media` element from `grayscale(1)` to `grayscale(0)`.
