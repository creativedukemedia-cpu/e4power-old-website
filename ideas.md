# E4 Power Phase 1 Homepage Direction

## Chosen design direction

The homepage redesign should follow the provided reference as the **ground-truth structural direction** for Phase 1. This means shifting away from the earlier forensic mirror approach and toward a clearer top-navigation and hero composition while preserving the strongest existing brand elements.

| Element | Direction |
| --- | --- |
| Header | Use a more traditional top navigation bar with the E4 logo left, primary destinations clearly visible, and social/contact access integrated in a cleaner way. |
| Hero background | Keep the current video background. |
| Hero services | Keep the visible services inside the hero. |
| Hero message | Replace the current logo-first opening with a direct value proposition that immediately explains who E4 serves, what E4 does, and why E4 is different. |
| Brand tone | Brighten the presentation selectively without abandoning the dark editorial atmosphere or gold accent system. |
| Trust hierarchy | Pull credibility elements higher in the page flow so partner recognition, service clarity, and proof appear sooner. |
| Signature element | Preserve the emblem interaction as a distinctive supporting device, but do not let it overpower message clarity. |

## Working design movement

The best label for this direction is **Strategic Institutional Beacon**. The site should feel more navigable, more assured, and more immediately understandable while still carrying the seriousness and cinematic quality that already suits the E4 brand.

The core principles are **clarity first**, **editorial restraint**, **visible proof**, and **structured confidence**. The color philosophy should keep charcoal, black, warm gold, soft ivory, and controlled transparent overlays, using brighter foreground planes and cleaner contrast rather than switching to a generic light corporate palette. The layout paradigm should use a legible navigation bar, a two-layer hero message structure, and earlier trust and service emphasis before the deeper narrative sections begin.

## Phase 1 message priorities

The first screen should communicate three ideas within seconds.

1. **Who E4 serves**: educational institutions, nonprofits, and mission-aligned organizations.
2. **What E4 does**: strategy, grant development, readiness, operational support, financial guidance, and technology-enabled capacity building.
3. **Why E4 is different**: E4 bridges strategy and execution across the full partnership lifecycle.

## Implementation guardrails

| Requirement | Instruction |
| --- | --- |
| Copy | Use direct, high-clarity language that is easier to scan than the current opening. |
| Motion | Keep movement restrained and intentional. The redesign should feel composed, not flashy. |
| Navigation | Reduce cognitive load for first-time visitors and make key destinations obvious. |
| Brightening | Brighten through cleaner panels, more breathing room, and improved contrast rather than a total palette reset. |
| Rollback safety | Save checkpoints before and after major structural changes. |
