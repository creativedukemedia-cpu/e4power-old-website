# E4 Power Hero Redesign Direction

## Ground-truth reference requirement

This pass must treat the user-provided homepage reference as the **primary visual specification** for the hero area. Fidelity to that reference takes priority over prior reinterpretations.

| Hero element | Required direction |
| --- | --- |
| Navigation | Use a traditional top bar with a gold left brand block and a dark primary navigation area, closely following the reference composition. |
| Hero background | Keep the video background, but darken it so the foreground hierarchy reads clearly. |
| Bridge motif | Reintroduce a large bridge graphic inside the hero as a prominent compositional layer. |
| Emblem placement | Keep the E4 emblem centered above the headline, closer to the reference arrangement. |
| Hero headline | Use a direct centered headline block that feels visually similar to the reference, with gold emphasis on the brand word. |
| Supporting copy | Add a centered descriptive sentence beneath the headline explaining who E4 serves and what it does. |
| Services list | Keep the visible services in the hero, positioned as a lower supporting layer rather than replacing the main message. |
| Tone | The hero should feel brightened and more structured, but still dark, cinematic, and unmistakably E4. |

## Design guardrails

The header and hero should look **reference-led, not newly invented**. The main risk is over-designing or introducing a different layout logic than the one shown by the user. The next implementation should stay simple, compositional, and controlled.
